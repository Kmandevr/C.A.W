# Function library

Generated by `caw docs` from the engine's own documentation (`engine/src/builtins.cpp` and `engine/lib/*.caw`); don't edit by hand. The language itself is in [engine](engine.md). A compact version for AI agents is the [agent guide](agent-guide.md). Every example below is a whole module body (float mode) and CI checks that it compiles and makes sound.

Optional arguments are marked `?`. Names with a dot belong to a namespace (`env.adsr`, `drum.kick`).

## Maths

### `sin(x)`

Sine of x (radians). The same bits on every device.

- `x`: angle in radians

```
sin(time * 220 * 2 * pi) * 0.5
```

### `cos(x)`

Cosine of x (radians).

- `x`: angle in radians

```
cos(time * 220 * 2 * pi) * 0.5
```

### `tan(x)`

Tangent of x (radians); 0 where the cosine is exactly 0.

- `x`: angle in radians

```
clamp(tan(time * 110 * pi), -1, 1) * 0.3
```

### `abs(x)`

Absolute value.

- `x`: any number

```
abs(saw(110)) - 0.5
```

### `floor(x)`

Largest whole number not above x.

- `x`: any number

```
floor(saw(110) * 4) / 4 * 0.5
```

### `ceil(x)`

Smallest whole number not below x.

- `x`: any number

```
ceil(saw(110) * 4) / 4 * 0.5
```

### `round(x)`

Nearest whole number; halves round up (like JavaScript).

- `x`: any number

```
round(sine(110) * 3) / 3 * 0.5
```

### `trunc(x)`

Drops the fraction (towards 0).

- `x`: any number

```
trunc(sine(110) * 3) / 3 * 0.5
```

### `sqrt(x)`

Square root; 0 for x <= 0.

- `x`: any number

```
sqrt(abs(sine(110))) * sign(sine(110)) * 0.5
```

### `exp(x)`

e to the power x.

- `x`: any number

```
sine(110) * exp(-fract(time * bpm / 60) * 6) * 0.6
```

### `log(x)`

Natural logarithm; 0 for x <= 0.

- `x`: a positive number

```
sine(110 + 40 * log(1 + step % 8)) * 0.5
```

### `tanh(x)`

Hyperbolic tangent: a smooth clipper.

- `x`: any number

```
tanh(saw(55) * 4) * 0.5
```

### `sign(x)`

-1, 0 or 1.

- `x`: any number

```
sign(sine(110)) * 0.3
```

### `fract(x)`

The part after the decimal point, 0..1 (also for negatives).

- `x`: any number

```
(fract(time * 110) * 2 - 1) * 0.5
```

### `mtof(note)`

MIDI note number to frequency in Hz (A4 = 69 = 440 Hz).

- `note`: MIDI note number (C4 = 60)

```
sine(mtof(A3)) * 0.5
```

### `min(a, b)`

The smaller of a and b.

- `a`: any number
- `b`: any number

```
min(saw(110), 0.2)
```

### `max(a, b)`

The larger of a and b.

- `a`: any number
- `b`: any number

```
max(saw(110), -0.2)
```

### `pow(x, y)`

x to the power y (exact for whole y; 0 when undefined).

- `x`: base
- `y`: exponent

```
sine(110) * pow(0.5, step % 4)
```

### `clamp(x, lo, hi)`

Keeps x between lo and hi.

- `x`: any number
- `lo`: lowest result
- `hi`: highest result

```
clamp(saw(110) * 3, -0.5, 0.5)
```

### `mix(a, b, amount)`

Blends from a (amount 0) to b (amount 1).

- `a`: first value
- `b`: second value
- `amount`: 0..1

```
mix(sine(110), saw(110), pos) * 0.5
```

### `beats(n)`

Seconds in n beats at the project tempo, for delay times and envelopes.

- `n`: beats (0.25 = a 16th)

```
fx.delay(saw(220) * ad(step % 8 == 0, 0.001, 0.1), beats(0.75), 0.5, 0.5)
```

## Bits

### `popcount(x)`

How many bits are 1 in x (as 32 bits).

- `x`: read as a 32-bit integer

```
sine(110 * (1 + popcount(step))) * 0.4
```

### `clz(x)`

Leading zero bits of x (32 for 0).

- `x`: read as a 32-bit integer

```
sine(55 * (1 + clz(step + 1) % 5)) * 0.4
```

### `ctz(x)`

Trailing zero bits of x (32 for 0).

- `x`: read as a 32-bit integer

```
sine(110 * (1 + ctz(step + 1) % 4)) * 0.4
```

### `bitrev(x)`

Reverses the 32 bits of x.

- `x`: read as a 32-bit integer

```
((bitrev(floor(time * 8000)) >>> 24) & 255) / 128 - 1
```

### `bswap(x)`

Reverses the 4 bytes of x.

- `x`: read as a 32-bit integer

```
((bswap(floor(time * 8000)) >>> 16) & 255) / 128 - 1
```

### `bits(x)`

The bits of x as a 32-bit float, read as an integer.

- `x`: any number

```
((bits(sine(110)) >> 16) & 255) / 128 - 1
```

### `float(i)`

The 32-bit float whose bits are i (the reverse of bits).

- `i`: read as a 32-bit integer

```
clamp(float(bits(sine(110)) ^ (step & 7)), -1, 1) * 0.5
```

### `rotl(x, n)`

Rotates the 32 bits of x left by n.

- `x`: read as a 32-bit integer
- `n`: places, 0..31

```
((rotl(floor(time * 8000), step % 8) >> 4) & 255) / 128 - 1
```

### `rotr(x, n)`

Rotates the 32 bits of x right by n.

- `x`: read as a 32-bit integer
- `n`: places, 0..31

```
((rotr(floor(time * 8000), 3) >> 1) & 255) / 128 - 1
```

## Random

### `hash(x)`

A repeatable 32-bit scramble of x; changes with the project seed.

- `x`: read as a 32-bit integer

```
sine(110 * (1 + hash(step) % 4)) * 0.4
```

### `noise(x?)`

White noise in -1..1 from t (or from x), the seed and the call's place in the code.

- `x` (optional): optional; what the noise follows (default t)

```
noise() * ad(step % 2 == 0, 0.001, 0.05) * 0.4
```

### `rand(x)`

A repeatable random number 0..1 for x (the same x gives the same value).

- `x`: anything that picks the value, e.g. step

```
sine(110 + 330 * rand(step)) * 0.4
```

### `randi(x, n)`

A repeatable random whole number 0..n-1 for x.

- `x`: anything that picks the value
- `n`: how many values

```
sine(mtof(scale(randi(step, 8)))) * 0.4
```

### `chance(x, p)`

1 with probability p for x, otherwise 0; repeatable.

- `x`: anything that picks the value, e.g. step
- `p`: probability 0..1

```
noise() * ad(chance(step, 0.6), 0.001, 0.04) * 0.4
```

## Oscillators

### `sine(freq)`

Sine wave, -1..1.

- `freq`: Hz

```
sine(220) * 0.5
```

### `saw(freq)`

Band-limited sawtooth, -1..1.

- `freq`: Hz

```
saw(110) * 0.4
```

### `square(freq, width?)`

Band-limited square/pulse wave, -1..1.

- `freq`: Hz
- `width` (optional): pulse width 0.01..0.99 (default 0.5)

```
square(110, 0.25) * 0.3
```

### `tri(freq)`

Triangle wave, -1..1.

- `freq`: Hz

```
tri(220) * 0.5
```

## Envelopes

### `ad(trig, attack?, decay?)`

Attack-decay envelope 0..1, started each time trig rises above 0.

- `trig`: starts the envelope when it goes above 0
- `attack` (optional): seconds (default 0.005)
- `decay` (optional): seconds to -60 dB (default 0.3)

```
sine(110) * ad(step % 4 == 0, 0.001, 0.3)
```

### `env.ar(trig, attack?, release?)`

Attack-release envelope 0..1, started each time trig rises (same as ad).

- `trig`: starts the envelope when it goes above 0
- `attack` (optional): seconds (default 0.005)
- `release` (optional): seconds to -60 dB (default 0.3)

```
saw(110) * env.ar(step % 4 == 0, 0.01, 0.2) * 0.5
```

### `env.adsr(gate, attack, decay, sustain, release)`

Attack-decay-sustain-release envelope 0..1: holds at sustain while gate is above 0, releases when it falls.

- `gate`: above 0 while the note is held
- `attack`: seconds
- `decay`: seconds to reach sustain
- `sustain`: level 0..1
- `release`: seconds to -60 dB after the gate falls

```
saw(110) * env.adsr(step % 4 < 2, 0.01, 0.1, 0.6, 0.2) * 0.5
```

### `slew(x, rise, fall?)`

Smooths x: moves toward it taking `rise` seconds up and `fall` seconds down. Good for glide and de-clicking.

- `x`: the value to follow
- `rise`: seconds when going up (default 0.05)
- `fall` (optional): seconds when going down (default: same as rise)

```
sine(slew(mtof(scale(step % 5)), 0.03)) * 0.5
```

## LFOs

### `lfo.sine(beats, phase?)`

Sine LFO -1..1 synced to the tempo.

- `beats`: length of one cycle in beats
- `phase` (optional): start point 0..1 (default 0)

```
lpf(saw(55), 600 + 500 * lfo.sine(4), 4) * 0.5
```

### `lfo.tri(beats, phase?)`

Triangle LFO -1..1 synced to the tempo.

- `beats`: length of one cycle in beats
- `phase` (optional): start point 0..1 (default 0)

```
sine(220 + 50 * lfo.tri(1)) * 0.5
```

### `lfo.saw(beats, phase?)`

Rising saw LFO -1..1 synced to the tempo.

- `beats`: length of one cycle in beats
- `phase` (optional): start point 0..1 (default 0)

```
sine(220 + 100 * lfo.saw(2)) * 0.5
```

### `lfo.square(beats, phase?)`

Square LFO (1 then -1) synced to the tempo.

- `beats`: length of one cycle in beats
- `phase` (optional): start point 0..1 (default 0)

```
sine(220 * (1.5 + 0.5 * lfo.square(1))) * 0.5
```

### `lfo.random(beats, phase?)`

A new random level -1..1 every cycle (stepped), synced to the tempo and the seed.

- `beats`: how long each level lasts, in beats
- `phase` (optional): start point 0..1 (default 0)

```
sine(330 + 200 * lfo.random(0.25)) * 0.5
```

## Filters

### `lpf(x, cutoff, q?)`

Low-pass state-variable filter (12 dB/octave).

- `x`: input
- `cutoff`: Hz
- `q` (optional): resonance 0.1..40 (default 0.707)

```
lpf(saw(55), 800, 4) * 0.5
```

### `hpf(x, cutoff, q?)`

High-pass state-variable filter (12 dB/octave).

- `x`: input
- `cutoff`: Hz
- `q` (optional): resonance 0.1..40 (default 0.707)

```
hpf(noise(), 6000) * 0.3
```

### `bpf(x, cutoff, q?)`

Band-pass state-variable filter.

- `x`: input
- `cutoff`: centre Hz
- `q` (optional): resonance 0.1..40 (default 0.707)

```
bpf(noise(), 1200, 6) * 0.8
```

### `notch(x, cutoff, q?)`

Notch (band-reject) state-variable filter.

- `x`: input
- `cutoff`: centre Hz
- `q` (optional): width 0.1..40 (default 0.707)

```
notch(saw(110), 1000, 2) * 0.4
```

### `lp1(x, cutoff)`

Gentle one-pole low-pass (6 dB/octave).

- `x`: input
- `cutoff`: Hz

```
lp1(noise(), 500) * 0.8
```

### `hp1(x, cutoff)`

Gentle one-pole high-pass (6 dB/octave); removes rumble and DC.

- `x`: input
- `cutoff`: Hz

```
hp1(saw(55), 200) * 0.5
```

## Effects

### `fx.drive(x, amount)`

Warm saturation (tanh), level-matched so full scale stays full scale.

- `x`: input
- `amount`: 1 = clean, 10 = heavy

```
fx.drive(sine(55), 8) * 0.5
```

### `fx.crush(x, bits)`

Bit crusher: rounds the sound to fewer bits.

- `x`: input
- `bits`: 1..24

```
fx.crush(sine(110), 3) * 0.5
```

### `fx.fold(x, drive)`

Wavefolder: more drive folds the wave back on itself.

- `x`: input
- `drive`: 1..12

```
fx.fold(sine(110), 4) * 0.5
```

### `fx.delay(x, time, feedback?, mix?)`

Echo with feedback, up to 2 s (at 96 kHz).

- `x`: input
- `time`: seconds (try beats(0.75))
- `feedback` (optional): 0..0.98 (default 0.4)
- `mix` (optional): dry 0 .. wet 1 (default 0.5)

```
fx.delay(saw(220) * ad(step % 8 == 0, 0.001, 0.08), beats(0.5), 0.6, 0.5)
```

### `fx.reverb(x, size?, damp?, mix?)`

Room reverb (mono Freeverb).

- `x`: input
- `size` (optional): 0..1 (default 0.7)
- `damp` (optional): high-frequency damping 0..1 (default 0.3)
- `mix` (optional): dry 0 .. wet 1 (default 0.3)

```
fx.reverb(noise() * ad(step % 8 == 0, 0.001, 0.05), 0.8, 0.3, 0.5)
```

### `fx.comp(x, threshold?, ratio?, attack?, release?)`

Compressor: turns down whatever goes above the threshold.

- `x`: input
- `threshold` (optional): dB, -60..0 (default -18)
- `ratio` (optional): 1..40 (default 4)
- `attack` (optional): seconds (default 0.005)
- `release` (optional): seconds (default 0.1)

```
fx.comp(saw(55) * ad(step % 4 == 0, 0.001, 0.4), -24, 8) * 1.5
```

## Glitch

### `glitch.hold(x, rate)`

Sample and hold: grabs a new value `rate` times a second and holds it.

- `x`: input
- `rate`: holds per second

```
glitch.hold(sine(220), 2000) * 0.5
```

### `glitch.stutter(x, on, length)`

While `on` is above 0, repeats the first `length` seconds heard after it rose (up to 1 s at 96 kHz).

- `x`: input
- `on`: above 0 while stuttering
- `length`: seconds to repeat

```
glitch.stutter(saw(110 + step * 20) * 0.4, step % 16 >= 12, beats(0.125))
```

### `glitch.mask(x, mask)`

Flips bits of the sound read as 16-bit numbers.

- `x`: input
- `mask`: bits to flip, 0..65535

```
glitch.mask(sine(110) * 0.5, 0x0F00)
```

### `glitch.wrap(x, amount)`

Pushes the sound past full scale and wraps it around to the other side.

- `x`: input
- `amount`: 1 = clean, more = wilder

```
glitch.wrap(sine(110), 3) * 0.5
```

## Music

### `scale(degree, scale?, root?)`

The MIDI note of a scale degree; degrees past the end continue into the next octave.

- `degree`: 0 = root, 1 = second note, ... (negative goes down)
- `scale` (optional): a scale.* constant (default: the project key's scale)
- `root` (optional): MIDI note of degree 0 (default: the project key in octave 4)

```
sine(mtof(scale(step % 8))) * ad(1, 0.005, 0.2) * 0.5
```

### `quantize(note, scale?, root?)`

Moves a MIDI note to the nearest note of the scale.

- `note`: MIDI note number
- `scale` (optional): a scale.* constant (default: the project key's scale)
- `root` (optional): any note of the key (default: the project key)

```
sine(mtof(quantize(48 + rand(step) * 24))) * 0.5
```

### `chord(type, index, root?)`

The index-th note of a chord; indexes past the end climb octaves.

- `type`: a chord.* constant
- `index`: 0 = root, 1 = next note, ...
- `root` (optional): MIDI note (default: the project key in octave 4)

```
(sine(mtof(chord(chord.min7, 0))) + sine(mtof(chord(chord.min7, 1))) + sine(mtof(chord(chord.min7, 2)))) * 0.2
```

### `arp(type, step, mode?, root?, octaves?)`

Walks through a chord one note per step (up, down, up-down or random).

- `type`: a chord.* constant
- `step`: which step of the arpeggio (e.g. step)
- `mode` (optional): an arp.* constant (default arp.up)
- `root` (optional): MIDI note (default: the project key in octave 4)
- `octaves` (optional): 1..4 (default 1)

```
saw(mtof(arp(chord.min, step, arp.updown, 57, 2))) * ad(1, 0.002, 0.1) * 0.4
```

### `euclid(hits, steps, pos, rotate?)`

1 on the steps where `hits` notes spread as evenly as possible over `steps`; otherwise 0.

- `hits`: how many notes
- `steps`: length of the pattern
- `pos`: which step (e.g. step)
- `rotate` (optional): shifts the pattern (default 0)

```
noise() * ad(euclid(5, 16, step), 0.001, 0.05) * 0.4
```

## Constants

- **`scale.*`**: Scales for scale() and quantize(): major, natural minor, the modes, harmonic and melodic minor, major and minor pentatonic, blues, chromatic and whole-tone. Values: `scale.major`, `scale.minor`, `scale.dorian`, `scale.phrygian`, `scale.lydian`, `scale.mixolydian`, `scale.locrian`, `scale.harmonic`, `scale.melodic`, `scale.pentatonic`, `scale.minorpenta`, `scale.blues`, `scale.chromatic`, `scale.whole`.
- **`chord.*`**: Chord shapes for chord() and arp(). Values: `chord.maj`, `chord.min`, `chord.dim`, `chord.aug`, `chord.sus2`, `chord.sus4`, `chord.maj7`, `chord.min7`, `chord.dom7`, `chord.maj9`, `chord.min9`, `chord.power`.
- **`arp.*`**: Arpeggio directions for arp(). Values: `arp.up`, `arp.down`, `arp.updown`, `arp.random`.

## Library: Drums (`drum.*`)

Drum voices built from oscillators, noise and envelopes. Written in the module language in `engine/lib/drum.caw`, so you can read how each one works.

### `drum.kick(trig, tune, decay)`

Kick drum: a sine whose pitch drops fast at the start of each hit.

- `trig`: starts a hit when it rises above 0, e.g. step % 4 == 0
- `tune`: lowest pitch in Hz, 35..80
- `decay`: seconds until it fades out

```
drum.kick(step % 4 == 0, 48, 0.35)
```

### `drum.snare(trig, tone, decay)`

Snare: a short tone body plus filtered noise.

- `trig`: starts a hit when it rises above 0
- `tone`: lowest noise frequency in Hz, 1000..6000 (higher is thinner)
- `decay`: seconds the noise rings, 0.05..0.4

```
drum.snare(step % 8 == 4, 2500, 0.18)
```

### `drum.hat(trig, open)`

Hi-hat: high-passed noise, short when closed, ringing when open.

- `trig`: starts a hit when it rises above 0
- `open`: 0 = closed, 1 = open

```
drum.hat(step % 2 == 0, step % 8 == 6)
```

### `drum.clap(trig, decay)`

Clap: band-passed noise with a soft attack.

- `trig`: starts a hit when it rises above 0
- `decay`: seconds until it fades out, 0.05..0.5

```
drum.clap(step % 8 == 4, 0.15)
```

## Library: Synths (`synth.*`)

Ready-made synth voices: supersaw, pluck, acid, pad and FM. Written in the module language in `engine/lib/synth.caw`, so you can read how each one works.

### `synth.supersaw(freq, detune)`

Five detuned saws: a wide, bright lead or chord sound.

- `freq`: Hz
- `detune`: spread between the saws, 0..0.05

```
synth.supersaw(mtof(A3), 0.012) * 0.4
```

### `synth.pluck(trig, freq, decay)`

Plucked string: a bright attack that darkens as it fades.

- `trig`: starts a note when it rises above 0
- `freq`: Hz
- `decay`: seconds until it fades out

```
synth.pluck(step % 2 == 0, mtof(scale(step % 8)), 0.4) * 0.6
```

### `synth.acid(gate, freq, cutoff, res)`

Acid bass: a resonant filtered saw that slides between notes.

- `gate`: above 0 while the note is held
- `freq`: Hz (slides when it changes)
- `cutoff`: Hz, 100..4000
- `res`: resonance, 1..20

```
synth.acid(step % 2 == 0, mtof(scale(step % 5) - 24), 700, 12) * 0.5
```

### `synth.pad(freq, bright)`

Soft pad: a filtered supersaw.

- `freq`: Hz
- `bright`: 0 = dark .. 1 = bright

```
synth.pad(mtof(chord(chord.min7, step % 4, 57)), 0.4) * 0.5
```

### `synth.fm(freq, ratio, index)`

Two-operator FM: a sine whose pitch is wobbled by another sine.

- `freq`: Hz
- `ratio`: modulator frequency as a multiple of freq (try 1, 2, 3.5)
- `index`: how hard it wobbles, 0..10 (more is brighter)

```
synth.fm(mtof(A2), 2, 3 * ad(step % 4 == 0, 0.001, 0.3)) * 0.5
```

## Library: Utilities (`util.*`)

Mixing helpers: sidechain ducking, gating and tremolo. Written in the module language in `engine/lib/util.caw`, so you can read how each one works.

### `util.duck(x, env, amount)`

Sidechain ducking: turns x down while an envelope is high (e.g. kick.env).

- `x`: the sound to duck
- `env`: 0..1, usually another module's export such as kick.env
- `amount`: 0 = no ducking, 1 = silent at the peak

```
util.duck(saw(55) * 0.5, ad(step % 4 == 0, 0.001, 0.3), 0.8)
```

### `util.gate(x, open)`

Rhythmic gate: lets x through only while open is above 0.

- `x`: the sound
- `open`: above 0 to let sound through, e.g. euclid(5, 16, step)

```
util.gate(saw(110) * 0.4, euclid(5, 16, step))
```

### `util.trem(x, length, depth)`

Tremolo synced to the tempo.

- `x`: the sound
- `length`: one wobble, in beats
- `depth`: 0..1

```
util.trem(saw(110) * 0.5, 0.25, 0.8)
```
