# C.A.W vault

Project memory for C.A.W. Open this `docs/` folder as a vault in Obsidian, or read it on GitHub. A note that documents code lists the paths it describes in its `covers:` frontmatter; re-check the note when those change.

## Notes

- [Vision](vision.md): the owner's brief, condensed, and the open-questions register; read before planning a feature
- [Architecture](architecture.md): stack, audio engine and code execution, module format, GitHub sync, AI workflow, risks
- [Engine and language reference](engine.md): the built engine: module language, playback, project file, exports, C API, CLI, tests
- [Function library](library.md): every built-in and library function with arguments and an example; generated by `caw docs`
- [Agent guide](agent-guide.md): the language and every function on one line each, for AI agents writing modules; generated by `caw docs`
- [App](app.md): the built Flutter app: areas, engine access, storage, build and signing
- [Performance](performance.md): how the engine and app are measured for low-end devices, the audit's ranked bottlenecks, fixes with before/after numbers, and next steps
- [Actions, keys and macros](actions.md): draft for review: every command as an action, customisable keys per area, macros, toolbars and the default keymap
- [UI design](ui.md): v2 layout and interactions for phone and desktop, gestures, editors, and the CPU and RAM budget
- [Roadmap](roadmap.md): v1 (build, arrange, export) and later stages, with v1's acceptance test and build order
- [Decisions](decisions.md): what was chosen and why
- [Log](log.md): dated history of changes
