# Security

Please report security problems privately through a [security advisory](https://github.com/Kmandevr/C.A.W/security/advisories/new), not a public issue. Only the maintainers see it.

In scope: the module sandbox (a sound file that escapes its limits, crashes the engine or reads anything outside it), GitHub sign-in and sync, secrets in the app or repository, Android permissions, and CI workflows.
